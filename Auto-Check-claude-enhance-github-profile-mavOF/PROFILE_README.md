### What I Build

I ship AI-powered tools that originate from real operational problems — not hypotheticals, not demos. Every repo here started because I hit a wall in my own work and decided to build through it.

**Enterprise AI Platforms**

- **[Haus-Nous](https://github.com/Raunaq-nous/Haus-Nous)** — An AI-first strategy consulting platform. Natural language console for business problem-solving, 12+ AI-powered consulting tools across Strategy, Operations, Finance, Analytics & Innovation, and a library of established consulting frameworks enhanced with AI. Built in TypeScript and Next.js.

- **[Auto-Check](https://github.com/Raunaq-nous/Auto-Check)** — Intelligent deck analysis and auto-correction system. Multi-model AI (GPT-4, Claude, Gemini, Llama, Mistral), RAG-powered fact-checking, grammar/style/numeric/chart validation, and a full change management UI with undo/redo. Built in Python, FastAPI, React, and TypeScript.

- **[Universal-RAG](https://github.com/Raunaq-nous/Universal-RAG)** — A production-grade retrieval-augmented generation engine built for structured retrieval across large document corpora — contracts, regulatory libraries, research archives. The kind of system that replaces hours of manual document search with seconds of queryable intelligence.

**Financial & Cost Intelligence**

- **[Financial-Modelling](https://github.com/Raunaq-nous/FInancial-Modelling)** — Agentic financial modeling platform with dynamic scenario comparison. Real-time CapEx, OpEx, and IRR analysis across multiple project concepts simultaneously. Built for the kind of capital allocation decisions where precision matters.

- **[FM](https://github.com/Raunaq-nous/FM)** — Standalone financial modeling engine. Purpose-built architecture for rapid financial scenario generation and sensitivity analysis.

- **[Solar-Cost-Modelling](https://github.com/Raunaq-nous/Solar-Cost-Modelling)** — Multi-agent solar PV cost modeling system with an advanced interactive UI. Dynamic cost scenario generation across project variables — designed to model the economics of utility-scale solar projects in real time.

**Energy & Infrastructure Intelligence**

- **[Solar-Project-Benchmarking](https://github.com/Raunaq-nous/Solar-Project-Benchmarking)** — Benchmarking tool for solar project performance analysis. Structured comparison across project KPIs, cost metrics, and operational parameters.

- **[Capital-Projects-Watcher](https://github.com/Raunaq-nous/Capital-Projects-Watcher)** — Portfolio-level capital project monitoring and opportunity trigger identification. Surfaces reallocation signals and sequencing conflicts before they become costly delays.

**AI-Powered Workflow Tools**

- **[Survey-Tool](https://github.com/Raunaq-nous/Survey-Tool)** — PULSE: An AI-powered survey intelligence platform that automates the end-to-end survey research lifecycle — from questionnaire design through analysis and insight extraction.

- **[Proposal-Builder](https://github.com/Raunaq-nous/Proposal-Builder)** — AI-driven proposal generation system. Structures and drafts professional proposals with context-aware content generation.

- **[Powerpoint-Generation](https://github.com/Raunaq-nous/Powerpoint-Generation)** — AI-powered presentation generation. Transforms structured inputs into polished, formatted slide decks.

### The Integrated Platform

Beyond the standalone tools, I've built a five-module integrated agentic AI platform designed for capital project environments:

| Module | What It Does |
|--------|-------------|
| **Document Intelligence Engine** | RAG-based structured retrieval across contract and regulatory libraries |
| **Automated Workplan Generator** | Multi-agent LLM system that automates project schedule logic |
| **Financial & Cost Estimator** | Dynamic scenario comparison with real-time CapEx/OpEx/IRR analysis |
| **Schedule Optimizer** | Knowledge graph-linked platform that surfaces sequencing conflicts |
| **Capital Allocation Mapper** | Analyzes portfolio-level investment data for reallocation signals |

Built in Python, LangChain, and Streamlit.
